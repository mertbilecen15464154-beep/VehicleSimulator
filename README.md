# VR Car Simulator & Interaction System (VTA)

An advanced VR vehicle interaction and simulation project built with Unity 3D, C#, and XR Interaction Toolkit, BNG Framework designed for the Meta Quest ecosystem.

### 🚀 Core Mechanics & Features (WIP)
* **VR Enter/Exit Vehicle System:** Smooth transition mechanics for entering and exiting the driver's seat in immersive VR.
* **Interactive Steering & Transmission:** Physics-based manual steering wheel rotation with custom gear shifting logic (Manual/Automatic options).
* **Vehicle Electronics & Utilities:** Functional indicators (turn signals), windshield wiper systems, and interactive roll-down windows.
* **Spatial Audio Integration:** Dynamic audio occlusion system where internal radio sound attenuation changes based on window states (muffling/escaping sound effects).

### 🛠️ Tech Stack
* **Game Engine:** Unity 3D (URP)
* **Language:** C#
* **VR SDK:** XR Interaction Toolkit / OpenXR
